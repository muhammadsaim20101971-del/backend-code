# Backend

Install the backend dependencies from this directory with `npm install`, then
start the API with `npm start`. The API listens on `http://localhost:5000`.

Set `MONGODB_URI` in the repository-root `.env` file before starting the API.
To insert the sample students, run `npm run seed`.

The React frontend is in the sibling `frontend/` directory. Run it separately
with `npm start` from that directory.
